# AI Banking Chat App

## Run locally

1. `npm install`
2. Copy `.env.example` to `.env.local`
3. Set `OPENAI_API_KEY` (OpenAI or OpenRouter key)
4. *(Optional)* Set `OPENAI_BASE_URL=https://openrouter.ai/api/v1` for OpenRouter
5. *(Optional)* Set `OPENAI_MODEL` (defaults to `gpt-4o-mini`)
6. Run `npm run dev`

## Test

- `npm test`
- `npm run test:e2e`
